# بررسی توسعهٔ منابع، ۱۴۰۵/۰۸/۲۰

این سند وضعیت همین بررسی را ثبت می‌کند؛ تعداد فعال به معنی تضمین تازگی یا سلامت همیشگی نیست. ۱۵ مسیر در ۸ گروه ناشر فعال‌اند. دریافت، تازگی و مشارکت در مرجع مستقل‌اند. README عمداً مختصر مانده است.

## قرارداد و اعتبارسنجی

Schema نسخهٔ ۳، بخش‌های prices و parsian و همان یک مسیر `/api/prices.json` را تعریف می‌کند. میانه فقط یک پیاده‌سازی در report.py دارد و همهٔ تست‌ها/CLI همان را فراخوانی می‌کنند. ۲۸ وزن ثابت داریم؛ وزن بدون دادهٔ مناسب null است. برای هر وزن زمان اعلام، زمان مشاهده، اختلاف تومانی/ریالی، is_close و used_in_reference وجود دارد. تاریخچه یا commit خودکار قیمت اضافه نشده است.

تست‌های جدید، واحد/عیار/وزن، عدم مقیاس‌کردن وزن‌ها، ارزش خام در برابر محصول، نرخ منفی/صفر، زمان ساخت صفحه در برابر زمان نرخ، ساعت ناقص TGJU، تتر ریالی در برابر دلاری و رأی مشترک ناشر را پوشش می‌دهند. دریافت زنده و JSON واقعی جدا از تست‌ها بررسی شدند؛ گزارش اجراها در خروجی تحویل اعلام می‌شود. داده‌های خام بررسی در public یا Git قرار نمی‌گیرند.

## باقی‌مانده

برای فعال‌کردن منابع غیرفعال بالا باید زمان واقعی و واحد/نوع نرخ تأیید شود؛ استخراج عدد به‌تنهایی کافی نیست. مشکل ثبت نامنظم رویدادهای GitHub schedule هنوز رفع‌شده تأیید نشده؛ cron هر ۱۰ دقیقه است، اما اجرای دقیق GitHub تضمین ندارد. بنر تغییر قالب توکن GitHub یک اطلاعیهٔ عمومی است و خطای این collector نیست.
