# نتیجهٔ بررسی نهایی

این سند بررسی نسخهٔ پایه با ۷ مسیر است. بررسی افزوده‌شدن تبدیل و DollarGold و تصمیم دربارهٔ منابع درخواستی جدید در [NEW_SOURCES_VALIDATION.md](NEW_SOURCES_VALIDATION.md) آمده است؛ فهرست فعلی ۹ مسیر دارد.

تاریخ بررسی: ۱۴۰۵/۰۸/۱۹ (2026-11-10)، منطقهٔ زمانی Asia/Tehran.

## اصلاحات

- تطبیق دقیق عیار ۱۸؛ عیارهای ۱، ۸، ۸۱، ۲۴ و برچسب‌های مبهم پذیرفته نمی‌شوند.
- حذف حدس زمان TGJU از ساعت تنها، تاریخ خبر یا تاریخ دریافت. صفحات وب فاقد زمان کامل از فهرست فعال حذف شدند؛ بلوک قیمت لحظه‌ای کانال‌های رسمی به‌طور اختصاصی استخراج می‌شود.
- مرتب‌سازی timestampها پس از تبدیل به زمان واقعی UTC، حتی با offset متفاوت.
- تنها منطق تجمیع در build_report؛ حذف aggregate موازی و extract تکراری قدیمی. تست‌های تجمیع و CLI همین مسیر تولید خروجی را پوشش می‌دهند.
- جداسازی حباب، تک‌فروشی، عیار نامعلوم، بازار محلی و انواع نرخ خرید/فروش؛ تتر فقط midpoint زمان‌دار نوبیتکس است.
- استخراج زمان صریح آخرین بروزرسانی تابلوی اتحادیه و Ontala؛ دادهٔ بی‌زمان یا قدیمی هیچ رأیی در مرجع ندارد.
- قرارداد پنج‌فیلدی زمان از یک لحظه، IANA Asia/Tehran، تقویم شمسی معتبر، JSON Schema نسخهٔ ۲ و فیلدهای ثابت برای هر هشت قلم.

## محیط و تست‌ها

- محیط مجازی .venv با Python 3.12 ساخته شد؛ requirements-dev.txt و نصب editable پروژه موفق بودند.
- ۷۲ تست پاس شدند؛ pip check وابستگی ناسازگار پیدا نکرد.
- رگرسیون‌ها شامل عیار، TGJU، حباب، offset، مسیر کامل CLI، میانه، یک رأی برای ناشر، stale/future/unknown time، تبدیل واحد، علامت اختلاف، اونس بدون ریال، null، JSON Schema، مرز روز تهران و کبیسهٔ شمسی هستند.

## اجراهای واقعی با فهرست نهایی

قبل از این مرحله، یک اجرای اکتشافی برای هر ۵۰ مسیر انجام و پاسخ خام به‌صورت موقت بررسی شد؛ یک اجرای مقدماتی دیگر با ۶ مسیر انجام شد. سپس ۷ مسیر نهایی در سه اجرای کامل زیر ارزیابی شدند.

|---|---|---|---|---|
| 1 | 14:53:28 | 2026-11-10T11:23:28Z | 7/7 | تمام اقلام پیکربندی‌شدهٔ هر منبع، مثبت، زمان‌دار و تازه |
| 2 | 14:56:27 | 2026-11-10T11:26:27Z | 7/7 | تمام اقلام پیکربندی‌شدهٔ هر منبع، مثبت، زمان‌دار و تازه |
| 3 | 14:59:32 | 2026-11-10T11:29:32Z | 7/7 | تمام اقلام پیکربندی‌شدهٔ هر منبع، مثبت، زمان‌دار و تازه |

فاصلهٔ شروع اجراها حدود سه دقیقه بود. قیمت‌های تتر و برخی اقلام طلا/سکه تغییر کردند و hash خروجی هر اجرا متفاوت بود؛ نقرهٔ اکوگلد طی این بازه زمان/قیمت یکسان داشت ولی زمان اعلام آن هنوز داخل سقف ۹۰ دقیقه بود. دریافت جدید برای تازه‌کردن زمان قیمت استفاده نشد.

در بررسی خروجی، واحد و عیار، حضور تمام هشت کلید، نوع فیلدها، ساعت مشترک، سن واقعی timestampها، میانهٔ مشارکت‌کنندگان، یکتایی groupها و علامت/ضریب اختلاف‌ها کنترل شد. در آخرین اجرا JSON Schema نیز روی JSON خوانده‌شده از دیسک و HTTP اعمال شد.

## HTTP و انتشار

درخواست واقعی `GET /api/prices.json` از سرور موقت محلی روی `127.0.0.1` اجرا شد: status=200، Content-Type=`application/json`، JSON معتبر و برابر محتوای فایل نهایی. سرور پس از بررسی متوقف شد.

workflow به‌صورت YAML خوانده و تنظیمات cron برابر 7,37 * * * *، اجرای تست قبل از جمع‌آوری، Python 3.12، مسیر artifact برابر public، وابستگی deploy به collect و مجوزهای Pages/OIDC بررسی شدند. هیچ commit/push خودکار قیمت و هیچ مرحلهٔ تاریخچه اضافه نشده است.

در این پوشه .git، remote یا نشانی ریپوی مقصد وجود ندارد؛ بنابراین فعال‌بودن Pages، اجرای workflow روی GitHub و استقرار عمومی از این محیط تأیید نشده‌اند. فقط پیکربندی محلی و مسیر HTTP محلی تأیید شدند.

## منابع و محدودیت‌ها

- ۷ مسیر فعال، در ۵ group؛ Ontala صرفاً مقایسه‌ای است و چهار گروه دیگر امکان رأی مرجع دارند.
- تلگرام و بله در این محیط قابل دریافت بودند؛ محدودیت دسترسی دسته‌ای یا موفقیت ساختگی گزارش نشد.
- هر ۴۳ مسیر کنارگذاشته‌شده با دلیل دقیق در [SOURCES.md](SOURCES.md) آمده‌اند؛ پاسخ خام یا رکورد آن‌ها در خروجی عمومی نیست.
- سلامت ۱۰۰٪ یعنی هر ۷ مسیر در سه اجرای فوق تمام اقلام پیکربندی‌شدهٔ خود را معتبر و تازه برگرداندند. سلامت دائمی شبکه، استقلال اقتصادی کامل ناشران یا درستی مطلق نرخ‌ها تضمین نمی‌شود.
- برخی منابع ساعت‌به‌ساعت منتشر می‌کنند. سقف تازگی ۹۰ دقیقه قابل تنظیم است؛ خارج از آن، داده از مرجع حذف می‌شود و price می‌تواند null شود. قیمت قبلی بازاستفاده نمی‌شود.
- فایل عمومی فقط آخرین snapshot است. تاریخچهٔ قیمت، commit خودکار یا اطلاعات خام منابع اضافه نشده است.
- README بنا به درخواست کاربر فقط عنوان و معنی خروجی‌ها را نگه می‌دارد.
