# مسیر جایگزین دریافت از آروان

مسیرهای `arvan_*` پاسخ JSON پردازش لبهٔ آروان را با HTTPS برای رمزینکس، TGJU، اردیبهشت، دیجی‌کالا، پرسته و نرخ‌های اسپات ارزدیجیتال دریافت می‌کنند. هر کدام فقط نرخ و دارایی مشخص‌شدهٔ منبع خود را می‌پذیرد؛ وضعیت منبع، زمان دریافت آروان، واحد، نوع نرخ و زمان داده بررسی می‌شود. قیمت رمزینکس و دیگر تترها باید midpoint باشند و سقف سن تتر پنج دقیقه است. نرخ تکراری، نامعتبر یا نامرتبط رد می‌شود.

هر مسیر آروان در گروه همان ناشر/صرافی اصلی است، نه یک رأی مستقل. وقتی مسیر غیرآروان همان گروه نرخ واجد شرایط دارد، همیشه مقدم است. پرسته همچنان فقط مقایسه‌ای است. زمان snapshot یا زمان مشاهده از آروان به زمان اعلام نرخ تبدیل نمی‌شود؛ در انتخاب snapshot یا زمان مشاهده، هشدارهای معمول در خروجی باقی می‌مانند. در رمزینکس زمان ثبت‌شده آخرین تغییر یکی از سطوح دفتر سفارش است، نه تضمین تازگی هر دو سمت.

آروان منبع کاملاً مستقل نیست: اگر API بالادست یا پردازش لبهٔ آروان در دسترس نباشد، مسیر جایگزین هم ناموفق است. تمام مسیرها بدون رمز و با نشانی HTTPS ثابت خوانده می‌شوند و بدنه و timestamp آن‌ها اعتبارسنجی می‌شود. نتیجهٔ HTTP 200 یا `generated_at` به‌تنهایی اثبات تازگی نرخ نیست.

در آزمایش GitHub Actions شمارهٔ 44040476766 در 2026-11-17، دریافت رمزینکس، TGJU، ویجت TGJU، اردیبهشت و دادهٔ نوبیتکس/والکس از ارزدیجیتال موفق بود. ردیف رمزینکسِ ارزدیجیتال نرخ قابل پذیرش نداشت و مسیرهای دیجی‌کالا و پرسته timeout شدند؛ این آزمایش تضمین پایداری آینده نیست.
