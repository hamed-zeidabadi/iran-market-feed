# اعتبارسنجی منابع جدید، ۱۴۰۵/۰۸/۱۹

## نتیجهٔ منابع درخواستی

- تبدیل: endpointهای REST رسمی depth و trades بررسی شدند. اولی زمان اعلام نداشت و دومی last_trade بود. stream عمومی اسپات، snapshot دارای زمان E می‌دهد؛ midpoint تومان از بهترین سفارش‌های دارای حجم مثبت استخراج می‌شود و هم‌نوع با midpoint نوبیتکس وارد مرجع است.
- DollarGold_24: پیش‌نمایش عمومی و متن واقعی پیام‌ها بررسی شدند. طلا ۱۸، چهار نوع سکه، اونس و تتر قابل تشخیص‌اند. زمان از تاریخ/ساعت داخل متن است. نقره عیار ۹۹۹ ندارد و کنار گذاشته شد؛ خبر، تبلیغ، فوروارد و پیام بدون زمان رد می‌شوند. بالادست معلوم نیست، پس همهٔ اقلام فقط مقایسه‌ای‌اند؛ تتر آن indicative است.
- نوبیتکس: همان API زمان‌دار قبلی استفاده می‌شود؛ صفحهٔ معرفی رأی دوم نیست. دادهٔ priceDetails در HTML زمان قدیمی داشت. هیچ منبع مستقل تازه‌ای به نام صفحهٔ نوبیتکس ساخته نشد.
- ارزدیجیتال: در سه بررسی زنده، جدول بازنشر نوبیتکس شناسایی شد. نرخ اصلی دلاری با تومانی متفاوت است و نوع نرخ/زمان متصل به قیمت اصلی قابل تأیید نبود. منبع فعال جدید نشد و استقلال فرض نشد.
- بله با UID=4334467640: در سه دریافت HTTP، فقط پوستهٔ برنامه بود؛ نه هویت کانال، نه username عمومی و نه پیام. در کد عمومی برنامه guard ورود شناسایی شد. نگاشت این UID به مسیر عمومی بدون ورود تأیید نشد و URL جایگزین اختراع نشد.

## تست و اجرای محلی

- وابستگی‌های requirements-dev.txt در .venv نصب شدند؛ websocket-client==1.9.0 برای دریافت محدود یک snapshot اضافه شد. pip check موفق بود.
- ۹۰ تست پاس شدند؛ ۱۸ تست جدید نرخ/واحد، ریال-تومان، نوع نرخ، زمان رویداد در برابر ساعت سرور، رد بازار دلاری و اهرمی، اردربوک صفر/منفی/خالی/متقاطع، پایان اتصال، خبر/تبلیغ/فوروارد و یک رأی برای ناشر مشترک را پوشش می‌دهند.
- دو اجرای کامل موفق با فاصلهٔ سه دقیقه انجام شد. JSON واقعی با Schema، زمان مشترک، سن timestampها، واحدها، میانه، اختلاف و رأی ناشر بررسی شد:

| اجرا | پایان UTC | منابع موفق/فعال |
|---|---|---|
| 1 | 2026-11-10T11:54:56Z | 9/9 |
| 2 | 2026-11-10T11:57:56Z | 9/9 |

- اجرای سوم و یک تلاش دیگر با فاصله، با URLError برای تمام چهار مسیر تلگرام، شامل کانال‌های قبلی، روبه‌رو شدند. در هر دو اجرا سایر پنج منبع، از جمله تبدیل، موفق بودند. بررسی سلامت کامل این اجراها عمداً رد شد. قیمت یا زمان قدیمی برای ساخت موفقیت استفاده نشد.
- آخرین JSON محلیِ همین وضعیت خطای شبکه هم از نظر Schema و قرارداد ساعت معتبر است؛ چهار منبع تلگرام is_success=false دارند. این نتیجه با موفقیت کامل دریافت اشتباه گرفته نشده است.
- نتیجهٔ اجرای GitHub Actions و بررسی URL منتشرشده پس از push، در گزارش تحویل اعلام می‌شود. صحت شبکهٔ محلی به معنی سلامت دائمی یا برعکس نیست.

## حفظ قرارداد

همان هشت قلم و Schema نسخهٔ ۲ حفظ شده‌اند؛ تاریخ شمسی/ساعت ایران، UTC و Unix ثانیه تغییر نکرده‌اند. http_status برای WebSocket برابر null است. تتر مرجع فقط midpoint است و نرخ اعلامی کانال با آن مخلوط نمی‌شود. صفحه/API نوبیتکس یک group دارند. هیچ فایل قیمت یا پاسخ خام برای commit آماده نشده و تاریخچه‌ای اضافه نشده است. README مختصر بدون تغییر باقی مانده است.

## تکمیل بررسی در ۱۴۰۵/۰۸/۲۰

تغییرات منابع و زمان‌بندی ۱۰ دقیقه‌ای push شدند و اجرای GitHub collect/deploy موفق بود؛ ۹۱ تست در آن اجرا پاس شد. بررسی واقعی JSON نشان داد نوبیتکس HTTP 403 دارد و stream تبدیل timeout می‌شود. fallback عمومی معاملات تبدیل با نوع صریح last_trade اضافه شد؛ این نوع در مرجع midpoint رأی ندارد و timestamp قدیمی آن حفظ می‌شود. پس از این اصلاح ۹۵ تست پاس شد و اجرای محلی ۸ مسیر قابل استخراج از ۹ مسیر داشت؛ نوبیتکس همچنان 403 بود. دادهٔ معاملهٔ تبدیل در این بررسی قدیمی بود، بنابراین تازه اعلام نشد و نرخ مرجع تتر با آن پر نشد. زمان‌بندی و توضیح بررسی علت اجراهای نامنظم در AUTOMATION.md ثبت شده است.
