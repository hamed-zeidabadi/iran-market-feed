# مسیر جایگزین تتر از ارزدیجیتال

سه مسیر `arzdigital_nobitex`، `arzdigital_ramzinex` و `arzdigital_wallex` از API عمومی ارزدیجیتال استفاده می‌کنند. هر مسیر فقط ردیف اسپات همان صرافی را با جفت USDT/IRT می‌پذیرد. قیمت تتر برابر میانگین `bid` و `ask` به تومان است؛ نرخ‌های صفر، دفتر سفارش وارونه، جفت دیگر، رکورد تکراری یا غیرفعال رد می‌شوند. بیت‌پین در نمونهٔ بررسی‌شده bid و ask معتبر نداشت و به مرجع اضافه نشده است.

زمان `updated_at` زمان snapshot ارزدیجیتال در نظر گرفته می‌شود، نه زمان رویداد مستقیم صرافی. سقف سن این snapshot پنج دقیقه است؛ زمان تازه تضمین نمی‌کند هر دو سمت دفتر سفارش همان لحظه تغییر کرده باشند. در صورت مشارکت، هشدار `snapshot_contributor` ثبت می‌شود و زمان‌های اعلام تجمیعی نامشخص باقی می‌مانند. رأی‌ها از چند صرافی‌اند اما مسیر دریافت مشترک ارزدیجیتال است و از نظر انتقال داده وابسته‌اند.

مسیر هر صرافی در همان گروه منبع مستقیم قرار دارد، پس فقط یک رأی برای آن گروه شمرده می‌شود. نرخ مستقیم واجد شرایط با زمان اعلام معتبر مقدم است؛ در نبود آن، snapshot معتبر جایگزین می‌شود. معاملات آخر والکس یا بیت‌پین به جای midpoint استفاده نمی‌شوند. API هر سه مسیر در هر اجرای collector جداگانه دریافت می‌شود؛ آدرس مشترک به طور مشخص برای این adapter مجاز است.
